Motif sur mesure

Le client décrit son idée ou joint un modèle. Ces prix s'affichent dans le formulaire de commande.

Pour une réduction sur le sur-mesure, crée une offre dans l'onglet « Offres ».

Une collection limitée (un « drop ») a un lancement et une fin : avant, ses pièces sont cachées et la prochaine programmée affiche un décompte sur le site ; après la fin, elles quittent le site. Une collection permanente reste toujours en vente, sous le décompte.
