Motif sur mesure

Le client décrit son idée ou joint un modèle. Ces prix s'affichent dans le formulaire de commande.

Pour une réduction sur le sur-mesure, crée une offre dans l'onglet « Offres ».

Une offre baisse les prix d'un pourcentage pendant une période. Si deux offres visent la même pièce, la plus forte s'applique.
